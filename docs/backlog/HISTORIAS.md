## Sprint 1

### HU01 — Login y acceso según rol
Como usuario, quiero iniciar sesión para acceder solo a las funciones de mi rol.

### HU02 — Crear solicitudes
Como solicitante, quiero crear una solicitud para pedir soporte.

### HU03 — Consultar mis solicitudes
Como solicitante, quiero consultar mis solicitudes para conocer su estado.

### HU04 — Priorizar solicitudes
Como coordinador, quiero priorizar solicitudes para ordenar la atención.


## Sprint 2

### HU05 — Asignar solicitudes
Como coordinador, quiero asignar una solicitud para establecer responsabilidad.

### HU06 — Registrar comentarios
Como agente, quiero registrar comentarios de trabajo para documentar avances.

### HU07 — Cambiar estado
Como agente, quiero cambiar el estado para reflejar el flujo de atención.

### HU08 — Confirmar o reabrir solución
Como solicitante, quiero confirmar o reabrir una solución para controlar el cierre.


## Sprint 3

### HU09 — Buscar y filtrar solicitudes
Como usuario, quiero buscar y filtrar solicitudes para localizar información autorizada.

### HU10 — Indicadores
Como coordinador, quiero consultar indicadores agregados para gestionar el servicio.

### HU11 — Historial de auditoría
Como auditor, quiero consultar el historial para verificar decisiones.

### HU12 — Exportar reporte
Como coordinador, quiero exportar un reporte para análisis autorizado.
